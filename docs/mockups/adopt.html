How adoption works

The CloudFormation stack stays as it is; ownership moves to the repository.

1
Scan the account and pick an unmanaged stack.
2
Choose the repo, partition, set, and target pusher. Guardian derives the repo path and MonoFS path.
3
Open a pull request with the partition, intents, and payload binding.
4
Merge. The partition becomes Observed; Guardian never applied to the stack.
